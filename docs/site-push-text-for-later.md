# 通知（スタンプのお知らせ）の文の控え（通知を出す版で戻す）

5.2.3 は通知を隠して出す（アプリの `MeguriPostPushFeature.isEnabled = false`。5.2.3-C）ため、
5.2.3-H で `privacy.html` から通知の番号を預かる話を外した。ここにある文は、外す前（`7f52809`）のまま。
通知を出す版（`isEnabled` を true にした版）を出すときに、下の場所へ戻す。戻したら最終更新日を変え、
`docs/app-privacy-meguri-post.md` の「通知の番号」の判断メモもあわせて見直す。
`meguri-post-terms.html`（規約）には、通知の文はもともと無い。

## privacy.html

### はじめの文（lede）の括弧の中

外す前：

```
巡り便を使ったとき（出す・受け取る・「みんなの巡り」で見る・返事を送る・通報する・ブロックする・スタンプのお知らせをオンにする）に限り、
```

（「・スタンプのお知らせをオンにする」を外した）

### 07「送信される情報」のはじめの文

外す前：

```
<p>巡り便を投稿したとき、受け取ったとき、「みんなの巡り」で見たとき、返事を送ったとき、通報したとき、差出人をブロックしたとき、スタンプのお知らせをオンにしたときに、以下の情報が送信されます。</p>
```

（「、スタンプのお知らせをオンにしたとき」を外した）

### 07「送信される情報」の表の最後の行（「返事・通報・ブロック」の次）

```
        <tr>
          <th>通知の番号</th>
          <td>アプリの設定などで「スタンプが届いたら知らせる」をオンにし、通知を許可したときに限り、Apple のプッシュ通知用の番号（端末とアプリの組み合わせごとにAppleが発行する番号）を送ります。自分の巡り便にスタンプが付いたことを知らせるためだけに使います。通知の文は「スタンプの種類と数」だけで、巡り便の題・店名・地域・だれが押したかは通知に入れません。オフにすると、この番号と、まだ送っていないお知らせの記録をサーバーから削除します</td>
        </tr>
```

### 07「利用する目的」

外す前：

```
      <li>返事を差出人に届けるため。スタンプのお知らせをオンにした差出人には、スタンプが付いたことを通知で知らせるため（1時間に1回まで。夜は朝にまとめます）</li>
```

（「返事を差出人に届けるため」だけにした）

### 07「保存する期間と削除」（「ブロックの記録は…」の次）

```
      <li>通知の番号は、スタンプのお知らせをオフにしたとき、またはAppleがその番号を使えないと返したときに削除します。まだ送っていないお知らせの記録（識別番号・スタンプの数・送る時刻）は、通知を送ったときに削除します</li>
```
